# RO_TRNG TCAS-II Possible Plan

This file is local to the RO_TRNG entropy-boundary paper.

## Possible TCAS-II Framing

If compressed into a short IEEE TCAS-II-style paper, frame the work around one sharp circuits-and-systems contribution.

## Candidate Message

Sampler-side placement and implementation can reverse or materially change restart behavior in an FPGA RO-TRNG, so the sampler path should be considered part of the circuit-level entropy boundary.

## What Would Need To Be Cut

- Broad workflow detail.
- Long related-work discussion.
- Secondary placement cases.
- Exhaustive reproducibility narrative.

## Risks To Control

- TCAS-II would need a concise, circuit-centered technical insight, not a broad measurement report.
- Claims must be stronger and narrower than the current general manuscript plan.
- Evidence must support the central short-paper message without relying on many side experiments.
