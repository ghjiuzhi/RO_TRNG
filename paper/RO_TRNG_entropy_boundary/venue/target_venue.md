# Target Venue Plan

This file is local to the RO_TRNG entropy-boundary paper. It records the current submission strategy for this manuscript and is not a reusable venue template.

## Current Strategy

| Role | Venue | Current rationale |
| --- | --- | --- |
| Primary target | IEEE Transactions on Instrumentation and Measurement | Best fit if the paper is framed as measurement-driven characterization, diagnosis, and evidence-backed boundary definition. |
| Fallback | IEEE Access | Suitable if the paper is expanded around engineering completeness, reproducibility, and broad FPGA/security relevance. |
| Possible future target | IEEE TCAS-II | Possible only if compressed into a short circuits-and-systems contribution with a sharp technical message. |
| Possible future target | IEEE TVLSI | Possible only after stronger implementation, multi-board/PVT, resource, timing, power, and design-rule evidence. |
| Possible future target | Journal of Cryptographic Engineering | Possible only after stronger entropy-source modeling, security evaluation, SP800-90B boundary argument, health tests, and conditioning discussion. |

## Operating Rule

- Keep the paper root named by research theme: `RO_TRNG_entropy_boundary`.
- Keep current submission decisions in `venue/` and later submitted packages in `submissions/`.
- Use global venue profiles only for general writing guidance; keep RO_TRNG-specific submission strategy here.
- Do not hard-code the final venue into the manuscript until the target is confirmed for that submission round.
