# RO_TRNG JCEN Possible Plan

This file is local to the RO_TRNG entropy-boundary paper.

## Possible JCEN Framing

Journal of Cryptographic Engineering becomes plausible if the work is strengthened around entropy-source modeling, security evaluation, and validation boundaries.

## Evidence Needed Before Targeting JCEN

- Stronger entropy-source model.
- Clearer security evaluation and threat assumptions.
- SP800-90B boundary argument with explicit component definitions.
- Health-test and restart-test interpretation.
- Conditioning path and min-entropy accounting.
- Robust discussion of what the evidence does and does not certify.

## Risks To Control

- Do not overstate SP800-90B compliance.
- Avoid treating measurement observations as a complete cryptographic security argument.
- Keep JCEN as a future possible target unless the security-evaluation package is expanded.
