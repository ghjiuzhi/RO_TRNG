# RO_TRNG TVLSI Possible Plan

This file is local to the RO_TRNG entropy-boundary paper.

## Possible TVLSI Framing

IEEE TVLSI becomes plausible only if the paper grows into a VLSI implementation and design-methodology contribution, not only a measurement study.

## Evidence Needed Before Targeting TVLSI

- Multi-board evidence.
- PVT variation evidence.
- Resource, timing, and power characterization.
- Placement-aware implementation rules or design methodology.
- Toolflow reproducibility and sensitivity analysis.
- Clear comparison against implementation alternatives.

## Risks To Control

- Do not pitch TVLSI without enough implementation-depth evidence.
- Avoid claiming a mature placement-aware design rule before it is validated.
- Keep current TVLSI discussion as a future path, not the active submission plan.
