# RO_TRNG Entropy Boundary Paper Workspace

This directory is the project-local workspace for the RO_TRNG entropy-boundary manuscript.

The root name is based on the research theme, not on a journal target. Current submission strategy is tracked in `venue/`, and any future submitted packages should be stored in `submissions/`.

## Current Venue Strategy

- Primary target: IEEE Transactions on Instrumentation and Measurement.
- Fallback target: IEEE Access.
- Future possible targets after evidence expansion: IEEE TCAS-II, IEEE TVLSI, and Journal of Cryptographic Engineering.

These targets are planning notes, not hard-coded manuscript commitments.

## Directory Roles

- `manuscript/` - LaTeX manuscript skeleton and later drafts.
- `refs/` - BibTeX database.
- `figures/` - paper-local figure outputs or copied publication figures.
- `evidence/` - claim-evidence table, evidence gaps, related-work matrix, and figure/table plan.
- `notes/` - project evidence map, writing log, and local skill draft material.
- `venue/` - RO_TRNG-specific submission strategy and venue adaptation plans.
- `submissions/` - future submission or revision packages.

## Boundary Rule

Use global venue profiles only as reusable style guidance. Keep RO_TRNG-specific claims, evidence, target decisions, and submission plans in this workspace.
