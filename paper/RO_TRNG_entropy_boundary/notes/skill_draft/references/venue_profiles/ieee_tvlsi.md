# IEEE TVLSI Venue Profile

Use this profile as general guidance for IEEE Transactions on Very Large Scale Integration Systems-style manuscripts. Do not include project-specific claims here.

## Good Fit

- VLSI architectures, implementation methods, design automation, physical design effects, and hardware evaluation.
- Papers with strong implementation evidence: area, timing, power, scalability, design rules, and toolflow analysis.
- Work that contributes a validated hardware design method or architecture.

## Writing Emphasis

- Present the architecture or implementation methodology as a first-class contribution.
- Report resource use, timing, power, frequency, scalability, and implementation constraints.
- Explain physical design assumptions and placement/routing implications.
- Compare against relevant hardware baselines.
- Separate design rules from observations until validation is strong.

## Common Risks

- Insufficient implementation-depth evidence.
- Missing power, timing, or resource analysis.
- Overstating a design rule based on narrow experiments.
- Treating measurement-only results as a full VLSI methodology.

## Revision Focus

- Add implementation metrics and repeatability.
- Strengthen physical-design reasoning.
- Show how the design method transfers across configurations.
