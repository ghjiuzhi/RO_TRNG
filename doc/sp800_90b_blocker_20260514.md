## Next Installation Steps

Recommended Windows path:

1. Install MSYS2 from `https://www.msys2.org/`.
2. Open the MSYS2 MinGW64 shell.
3. Install the required build tools and libraries:

```bash
pacman -S --needed \
  base-devel \
  mingw-w64-x86_64-gcc \
  mingw-w64-x86_64-make \
  mingw-w64-x86_64-bzip2 \
  mingw-w64-x86_64-jsoncpp \
  mingw-w64-x86_64-openssl \
  mingw-w64-x86_64-gmp \
  mingw-w64-x86_64-mpfr
```

4. Install `divsufsort` for the same MinGW64 environment. If no MSYS2 package is available, build and install `libdivsufsort` from source with CMake into the MinGW64 prefix, ensuring both `libdivsufsort` and `libdivsufsort64` are available to the linker.
5. Add the MSYS2 MinGW64 `bin` directory to PATH for the shell used by this repo, or run all build commands from the MSYS2 MinGW64 shell.

Linux/WSL alternative:

```bash
sudo apt-get update
sudo apt-get install -y build-essential libbz2-dev libdivsufsort-dev libjsoncpp-dev libssl-dev libmpfr-dev
```
